# disk-radar

A small local page for macOS that shows which folders and files actually take disk space, and moves the ones you choose to the Trash.

disk-radar показывает, какие папки и файлы на Mac действительно занимают место, и убирает выбранное в Корзину. Список файлов никуда не отправляется: страница открывается только на этом компьютере.

## Цель

Узнать, куда делось место на диске, не гадая по «логическому» размеру в свойствах файла. Программа меряет занятые блоки, поэтому заглушка в iCloud или разреженный образ не выглядит больше, чем он есть на диске. Ненужное уходит в Корзину, и его можно вернуть, пока Корзину не очистили вручную.

## Требования

- macOS, на котором есть `du`, `find` и Finder. Это часть системы, отдельно их ставить не нужно.
- Python 3.9 или новее, доступный как `python3`.
- Домашний каталог, который ваш пользователь может читать.
- Полный доступ к диску не нужен. Папки, которые macOS не отдаёт, остаются в списке со статусом «нет доступа».
- Интернет нужен только чтобы клонировать репозиторий. Сама программа в сеть не ходит.

При первой отправке в Корзину macOS спросит разрешение управлять Finder у программы, из которой вы запустили `python3`. Без этого разрешения список файлов работает, а убрать объект в Корзину нельзя.

## Установка

```bash
git clone https://github.com/bobrov-site/disk-radar.git
cd disk-radar
python3 app.py
```

Отдельных пакетов нет. Команда печатает адрес вида `http://127.0.0.1:<порт>/` и открывает его в браузере. Остановить сервер: Ctrl+C в том же терминале.

## Сценарии

- Открыть программу и увидеть, сколько места занимают папки домашнего каталога.
- Зайти в `Library`, кэш или другую тяжёлую папку и открывать её уровень за уровнем, пока не станет понятно, что именно разрослось.
- Включить переключатель «Крупные файлы» или задать порог в гигабайтах. Поиск начинается сразу, файлы крупнее порога появляются в списке по мере нахождения. Повторное нажатие возвращает список текущей папки. Минимальный порог — 1 ГБ.
- Вернуться к папке, которую уже открывали в этом сеансе: список показывается сразу, без повторного запроса.
- Найти строку по имени в поле «Поиск»: список сужается по мере ввода. Упорядочить таблицу заголовками «Имя», «Изменён» и «На диске». Повторный щелчок по тому же заголовку меняет порядок на обратный.
- Отметить старую копию или кэш и убрать их в Корзину. Если это оказалось ошибкой, вернуть объекты из Корзины обычным способом macOS.
- Сравнить размер на диске с числом в свойствах файла. Файл, у которого в свойствах написаны десятки гигабайт, может занимать заметно меньше.
